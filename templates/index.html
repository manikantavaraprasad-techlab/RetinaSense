Reference ranges used

How the prediction is computed

  • Six biomarkers are measured from the vessel mask and artery/vein masks of the uploaded image.
  • Each biomarker's distance from its reference range is expressed in range-widths (0 = inside the range).
  • Every condition collects weighted evidence only from deviations in its own direction; Normal wins when everything is inside the ranges.
  • A softmax turns the scores into the match % shown. It is a pattern-match score, not a calibrated probability.
  • If the artery/vein split came from the colour heuristic, AVR-derived evidence is down-weighted, and a warning is printed.

Limits you should state when presenting

  • Decision-support only — not a diagnosis. Glaucoma is normally assessed from the optic disc and eye pressure; here it is inferred from vessel rarefaction and narrowing, which is indirect.
  • Pixel-based widths depend on image resolution; compare images of similar size.
  • Segmentation Dice is about 0.79 and artery/vein accuracy about 66 % in the saved evaluation, so single-image biomarker values carry measurement error.
  • Run python validate_screening.py labelled/ on images with known diagnoses to get a real accuracy and confusion matrix before quoting any accuracy.
